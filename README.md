# Kids learning 
This is kids learning app, It is for pre-schools age kids

## Colors 
Colors will be vibrant 

## Data 
For now all data store as json data inside data dir


## Features 

### Home screen 
Route Name - Home
Where list of category will be visible 
list of category can be for now

- Alphabets 
- Numbers
- Colors 
- Fruits 
- Vegetables 
- Animals
- Toys  

### Category details 
routes name - CategoryDetails
Category details based category name load json data and display swipeble card which contains images and text and some others info
